# Binkd Rust rewrite

There is an established code base in the repo.
The task is to cover it with tests as much as possible. Then prepare a plan of gradual rewrite of it in an idiomatic Rust programming language.
It is absolutely critical to maintain full functional equivalence of implementations.
We can replace modules one by one if needed.
It is desirable to maintain configs interoperability at this point.
It is necessary to provide an option for final implementation to be useable as library to be embeddable in other programs.

Gather all necessary information and prepare a full action plan.
